# Menjalankan proyek di Replit

Proyek ini menggunakan React, Vite, TypeScript, dan Bun.

- Workflow utama: `Start application`
- Preview berjalan pada port `5000`
- Perintah lokal: `PORT=5000 bun run dev`
- Build produksi: `bun run build`

Server aplikasi menyajikan build Vite dan menyediakan endpoint backend internal.
